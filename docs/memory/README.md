# Índice de memoria

Decisiones del proyecto, organizadas para consultar solo lo necesario. No es un historial de conversación.

| Tema de la tarea                             | Bloque que consultar              |
| -------------------------------------------- | --------------------------------- |
| Escuela, diseño, calendario y funcionamiento | [Producto](product.md)            |
| Lichess, administración y profesores         | [Identidad y permisos](access.md) |
| Cuotas, IVA, facturas y reparto docente      | [Pagos](billing.md)               |
| GitHub, Cloudflare, datos y verificaciones   | [Operación](operations.md)        |

Buscar en el bloque elegido las rutas de código o la documentación especializada. Ampliar la lectura solo si existe una dependencia real.

Al cambiar una decisión, corregir su bloque y cualquier documento de detalle que la contradiga. No guardar tokens, resultados temporales de herramientas, identificadores de despliegues ni copias de conversaciones. No tratar una comprobación antigua como estado actual.
